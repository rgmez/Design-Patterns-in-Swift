## Release summary

The candidate turns the complete Gang of Four catalogue into one executable
Swift learning system:

- 5 creational, 7 structural, and 11 behavioral patterns start from real app
  requirements instead of generic `Product` and `Creator` examples;
- every pattern follows the same decision path from direct Swift, through
  observable change pressure, to the smallest justified pattern boundary;
- every canonical guide records trade-offs, nearby alternatives, and an
  explicit `When not to use it` decision;
- one tested no-pattern case keeps a pure `URLComponents` solution when no
  staged construction pressure exists; and
- `choose-swift-design-pattern` turns the catalogue's evidence gates into a
  reusable decision skill without treating pattern selection as a quota.

The package requires Swift 6.0 or later and declares macOS 14 or later. All
examples compile in one `DesignPatterns` library target and are exercised by
one Swift Testing target.

## Architectural decision and avoided complexity

The bonus track narrowed two production APIs: Singleton no longer exports a
shared storage accessor, and Flyweight names its deterministic measurement as
payload rather than process memory. Other stages add test-only alternatives,
boundary evidence, and documentation without creating competing production
architectures. No visual needed correction.

The repository still has no shared pattern registry, universal participant
protocol, dependency-injection container, diagram generator, test base class,
or framework that forces unlike examples into one shape. Consistent guides,
package boundaries, and quality gates provide discoverability without adding a
second architecture above the examples.
